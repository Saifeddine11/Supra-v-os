# Quick Start — Administrateur

**Supra v. Agency OS** · **~10 minutes** · `https://app.suprav3.com`

## Les 7 actions du premier jour

1. Se connecter → vérifier le **tableau de bord**.  
2. **Paramètres** → identité d’agence + onglet **Intégrations**.  
3. **Équipe** → **Nouveau membre** (fiche sans connexion tout de suite = normal).  
4. **Clients** → fiche → **Portail** → copier le **lien complet** pour un test.  
5. **Devis** → exemple → **PDF**.  
6. **Factures** ou **Paiements** → parcourir un exemple.  
7. **Paramètres → Notifications** → vos **e-mails de rappel**.

## À ne pas faire

- Publier un **lien portail** sur un canal ouvert.  
- Partager une **clé secrète** serveur (chat, capture d’écran).
