# Quick Start — Équipe

**Supra v. Agency OS** · **~5 minutes** · pas d’accès **portail client** depuis ce compte

## Démarrage

1. **Tableau de bord** + **Notifications**.  
2. **Tâches** (statuts / échéances) ou **Calendrier tâches**.  
3. **Vidéos** si concerné (aperçu / lien final).  
4. **Paramètres** : thème + **rappels e-mail**.  
5. **Accès refusé** → demander à l’**admin** (ce n’est pas une panne).

## Par métier

| Métier | En priorité |
|--------|-------------|
| Chef de projet | Tâches, Projets, Vidéos, Clients |
| Commercial / **Finance** | Clients, Devis, Factures, Paiements |
| Monteur / caméraman | Vidéos, Tâches |
| Autres | Tâches, Projets |
