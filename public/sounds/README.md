# Sons de notification (optionnels)

Si vous ajoutez des fichiers **courts** (< 1 s) ici, l’app les utilisera en priorité ; sinon une courte synthèse Web Audio est jouée.

Fichiers attendus (noms exacts) :

- `notification-soft.mp3`
- `notification-important.mp3`
- `notification-urgent.mp3`
- `notification-critical.mp3`

Formats : **MP3** ou **WAV** léger, volume modéré (les préférences utilisateur appliquent encore un gain).
