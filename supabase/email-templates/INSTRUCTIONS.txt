Coller manuellement dans Supabase Dashboard :
  Authentication → Email Templates → Invite user

Subject :
  Invitation à rejoindre Supra v. Agency OS

Body : copier invite-user.html (onglet Body HTML) et invite-user.txt (Body plain).

URL Configuration (même onglet Authentication) :
  Site URL : https://app.suprav3.com
  Redirect URLs : inclure https://app.suprav3.com/** , https://appsupra.vercel.app/** , http://localhost:3000/** , etc.

Code : inviteUserByEmail utilise NEXT_PUBLIC_APP_URL pour redirectTo (voir src/lib/employees/auth-provision.ts).

Expéditeur « Supabase Auth » : activer Custom SMTP (ex. Resend) dans Project Settings → Authentication → SMTP Settings ; définir le nom d’affichage « Supra v. » et l’adresse notifications@app.suprav3.com (ou votre domaine vérifié).
